# Student Performance Analysis and MIS Reporting Using Advanced Excel

## Project Overview
Analyzed 6,607 student records using Advanced Excel and Power Query to develop structured MIS reports and evaluate academic performance.

## Tools Used
- Microsoft Excel
- Power Query
- Advanced Excel Formulas
- PivotTables and PivotCharts

## Key Skills
- Data Cleaning and Validation
- VLOOKUP, XLOOKUP and INDEX-MATCH
- IF, IFERROR, COUNTIFS and SUMIFS
- MIS Summary Reporting
- PivotTable Analysis and Data Visualization

## Key Findings
- Total Students: 6,607
- Average Attendance: 79.98%
- Average Exam Score: 67.24
- Students Below 75% Attendance: 2,396
- Students Scoring 80 or Above: 48
- High Motivation Students: 1,319

## Project Deliverables
- Cleaned Student Dataset
- Formula-Based Data Analysis
- MIS Summary Report
- PivotTables and Four PivotCharts

## Data Quality Note
An exam score of 101 was identified and retained pending confirmation of the grading rules.

## Conclusion
This project demonstrates practical Excel-based data analysis, data validation, and MIS reporting skills relevant to an entry-level MIS Executive role.
